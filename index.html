👋 Selamat Datang di Panel Admin ◉Multi Bani Family Tree
Halaman ini digunakan untuk mengelola data anggota keluarga. Mohon luangkan waktu sejenak untuk membaca panduan berikut sebelum melakukan perubahan agar struktur Family Tree tetap rapi, akurat, dan mudah dipahami oleh seluruh anggota keluarga.

🧭 Prosedur Admin

Sebelum masuk ke Panel Admin, harap memperhatikan hal-hal berikut:

  • ✅ Pastikan data yang diubah sudah benar.
  • 🔒 Pastikan selalu Logout setelah selesai.
  • 🛡️ Gunakan hak akses admin dengan bijak.
⚠️ Aturan Penting Sebelum Edit
  • Jangan mengganti ID lama.
  • Pastikan relasi keluarga benar.
  • Backup sebelum perubahan besar.
🚀 Panduan Cepat
💡 Tips
  • Gunakan kolom pencarian "ID yang ingin dilihat" untuk mencari ID dari data nama sesuai di Family Tree
➕ Menambah Data
  1. Father ID = ID Ayah
  2. Mother ID = ID Ibu
  3. Partner ID = ID Pasangan
  4. Input ID: masukkan nomor ID berdasarkan 📌 Informasi ID Terakhir
  5. Input Father ID, Mother ID, Partner ID: masukkan nomor ID / Nama sesuai data tersimpan di database firestore berdasarkan relasi antar ID
  6. Klik Tambah
✏️ Mengubah Data
  1. 1. Cari data di kolom pencarian "ID yang ingin dilihat"
  2. 2. Klik hasil pencarian hingga mode edit aktif
  3. 3. Ubah nama / foto sesuai kebutuhan
  4. 4. Klik Update
  5. ⚠️ Tidak dapat merubah Father ID, Mother ID, dan Partner ID
  6. ⚠️ Untuk memperbaiki relasi Father ID, Mother ID atau Partner ID gunakan menu ⚙️ ID Control
🗑️ Menghapus Data
  1. 1. Cari data di kolom pencarian "ID yang ingin dilihat"
  2. 2. Klik hasil pencarian hingga mode edit aktif
  3. 3. Klik Hapus
  4. ⚠️ Menghapus data dapat memengaruhi struktur Family Tree.
📷 Mengelola Foto
  1. 1. Tidak bisa menambah foto pada proses data baru
  2. 2. Tambahkan foto pada data yang sudah ada
  3. 3. Ubah foto pada data yang sudah ada
  4. 4. Hapus foto pada data yang sudah ada
  5. 5. Ukuran foto maksimal 10 MB
  6. ⚠️ Klik Update untuk menyimpan foto di database Firestore agar foto dapat dilihat di ◉Multi Bani Family Tree
🔍 Mencari Data
  1. Cari data ID di kolom pencarian "ID yang ingin dilihat"
  2. Ketik nama sesuai Family Tree atau ID
  3. Klik Lihat Data
📚 Aturan Detail
🔢 Aturan ID
  1. ID adalah nomor yang digunakan sebagai pengganti nama untuk membentuk relasi dalam membangun family tree
  2. Gunakan ID berdasarkan 📌 Informasi ID Terakhir untuk data baru agar tidak terjadi duplikasi ID
  3. Jangan mengganti ID lama untuk data baru karena setiap ID merupakan identitas yang digunakan untuk menghubungkan relasi keluarga
📝 Aturan Nama
  1. Pastikan input nama lengkap untuk mencegah duplikasi nama
  2. Jika nama lengkap tidak diketahui, gunakan format:
    • ✅ Untuk laki laki: Saudara (nama) bin (nama ayah)
    • ✅ Untuk perempuan: Saudari (nama) binti (nama ayah)
    • Contoh: diketahui nama Ditty. Maka tuliskan: Saudari Ditty binti Thompson
  3. Jika nama lengkap pasangan tidak diketahui, gunakan format:
    • ✅ (nama pasangan) pasangan (nama utama)
    • Contoh: diketahui nama Ditty, pasangan dari Cade. Maka tuliskan: Ditty pasangan Cade
  4. Penulisan nama dengan format:
    • ✅ Saudara (nama) bin (nama ayah)
    • ✅ Saudari (nama) binti (nama ayah)
    • ✅ (nama pasangan) pasangan (nama utama)
    • bertujuan agar tidak terjadi duplikasi nama dan family tree dapat dipakai hingga > 100 generasi
💍 Aturan Pasangan
  1. Jika seseorang memiliki lebih dari 1 pasangan, tambahkan kode urutan pada nama pasangan:
    • ✅ (nama pasangan) P1 → pasangan pertama
    • ✅ (nama pasangan) P2 → pasangan kedua
    • ✅ (nama pasangan) P3 → pasangan ketiga
    • ✅ dan seterusnya
    • Penggunaan kode P bertujuan agar urutan pasangan tetap terbaca karena sistem hanya mampu membentuk 2 pernikahan yang berurutan
  2. Contoh: diketahui Cade memiliki pasangan Ditty(nama panggilan), Ditta(nama panggilan), Dita Karang(nama lengkap). Maka tuliskan:
    • ✅ nama di ID untuk Ditty: Ditty P1 pasangan Cade;
    • ✅ nama di ID untuk Ditty: Ditta P2 pasangan Cade;
    • ✅ nama di ID untuk Dita Karang: Dita Karang P3
🌳 Aturan Relasi
  1. 1. Father ID dan Mother ID harus sesuai dengan ID orang tua.
  2. 2. Setiap anak harus memiliki relasi orang tua yang benar agar sistem mengenali saudara kandung.
  3. 3. Urutan saudara akan terbentuk sesuai urutan input admin berdasarkan urutan kelahiran.
  4. 4. Partner ID harus saling terhubung antara pasangan.
  5. 5. Urutan pernikahan lebih dari 1 akan terbentuk sesuai urutan input admin berdasarkan urutan pernikahan.
  6. ⚠️ Kesalahan relasi dapat menyebabkan tampilan Family Tree tidak sesuai.
⚙️ ID Control
  • ⚙️ ID Control 🟢 ON selalu aktif untuk menjaga konsistensi pengelolaan data oleh admin keluarga
  • Gunakan menu ⚙️ ID Control untuk memperbaiki kesalahan relasi Father ID, Mother ID, atau Partner ID
  • Untuk mengubah relasi:
    1. Klik ⚙️ ID Control 🟢 ON → ⚙️ ID Control 🔴 OFF
    2. Perbaiki Father ID, Mother ID, atau Partner ID
    3. Klik Update
    4. Aktifkan kembali ⚙️ ID Control 🟢 ON
📋 Data Firestore
  • Gunakan menu 📋 Data Firestore untuk pengecekan semua data tersimpan yang terdiri atas Doc ID, ID, Nama, Father ID, Mother ID dan Partner ID
  • Doc ID adalah nomor unik berupa dokumen yang tersimpan di database firestore
  • ID adalah nomor pengganti identitas nama yang digunakan sistem dalam membentuk family tree
  • Father ID, Mother ID, dan Partner ID adalah relasi yang digunakan sistem dalam membentuk family tree
  • Gunakan fitur ini untuk melacak semua data tersimpan dan relasi ID yang terdapat pada sistem sebagai sumber pembentuk Family Tree
📥 Download Data
  • Gunakan menu 📥 Download Data sebagai backup data offline dan keperluan cetak dari silsilah keluarga
🕒 Activity Log
  • Gunakan menu 🕒 Activity Log untuk melihat riwayat aktivitas pada Panel Admin
  • Riwayat menampilkan waktu, pengguna, jenis aktivitas, dan data yang diubah
  • Gunakan fitur ini untuk melacak perubahan data dan mengetahui riwayat pengelolaan data
🔄 Refresh Data
  • Gunakan menu 🔄 Refresh Data setelah menambahkan data baru atau update data agar Family Tree memuat ulang data terbaru dari database firestore
  • Klik satu kali sebelum logout
🛠️ Maintenance
  1. Jika tampilan pohon berantakan, cek ID di kolom pencarian "ID yang ingin dilihat"
  2. ⚠️ Pastikan setiap data berisi nomor ID dan nama!
  3. ⚠️ Jika data tidak ditemukan di kolom pencarian "ID yang ingin dilihat", lakukan pengecekan data pada menu 📋 Data Firestore untuk memastikan data masih tersimpan di database!
  4. ⚠️ Pastikan setiap data saling sinkron / terhubung satu sama lain!
    • ✅ Sinkronisasi pasangan: Pastikan partner ID saling terhubung satu sama lain.
    • ✅ Relasi Pasangan lebih dari 1: Pastikan input data sesuai urutan pernikahan agar urutan keluarga ditampilkan dengan benar pada Family Tree.
    • ✅ Relasi Anak → Orang Tua: Pastikan ID terhubung dengan Father ID dan Mother ID dengan data ID orang tua yang benar.
    • ✅ Relasi Orang Tua → Anak: Pastikan Father ID dan Mother ID terhubung dengan ID anak.
    • ✅ Relasi saudara kandung: Pastikan ID antar saudara memiliki Father ID dan Mother ID yang sama agar sistem mengenali mereka sebagai saudara kandung.
    • ✅ Urutan saudara: Pastikan input data sesuai urutan kelahiran agar urutan pada Family Tree ditampilkan dengan benar.
    • ✅ Relasi saudara beda ayah/ibu: Pastikan input data sesuai Father ID dan Mother ID sesuai dengan data ID orang tua yang benar.
    • ✅ Urutan saudara beda ayah/ibu: Urutan akan mengikuti urutan pernikahan orang tua secara otomatis.
📌 Catatan Sistem ID
  • Bani Soedaryo - Marsiti menggunakan ID mulai dari nomor 1
  • Bani Karmeni - Djuwariah menggunakan ID mulai dari nomor 1000
  • Semua data berada dalam satu database firestore
  • Seluruh ID merupakan identitas global yang digunakan untuk membentuk relasi Family Tree
  • Pembagian nomor ID hanya digunakan sebagai aturan administrasi untuk mempermudah pengelolaan data oleh admin keluarga dan mencegah duplikasi penggunaan ID yang sama
  • Pembagian nomor ID mengikuti relasi keluarga berdasarkan Father ID, Mother ID, atau Partner ID secara sistemik, melalui manual input admin
  • Apabila nomor ID telah mencapai batas rentang, sistem akan otomatis melanjutkan ke rentang ID berikutnya secara otomatis
